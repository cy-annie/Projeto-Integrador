# Projeto Integrador - Luz Cidadã 💡

O **Luz Cidadã** é um software desenvolvido para melhorar a comunicação entre moradores, técnicos e gestores em relação a problemas do Sistema de Iluminação Pública. O objetivo é centralizar a abertura, o acompanhamento e a resolução de ocorrências de forma ágil e transparente.

## 🎯 Funcionalidades Previstas

- Cadastro e acesso por perfil (Morador, Técnico e Gestor);
- Registro de ocorrências de iluminação pública;
- Consulta e acompanhamento de chamados;
- Triagem e distribuição de ocorrências;
- Atualização e conclusão dos atendimentos;
- Visualização de ocorrências em mapa;
- Painel de indicadores e relatórios;
- Histórico e rastreabilidade das alterações.

## 🚀 Tecnologias Utilizadas

- **Python 3**
- **Streamlit** (Framework para criação da interface web)
- **Git & GitHub** (Controle de versão e colaboração)
